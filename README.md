# 🐍 Python Development Internship Projects(Q-SKILL)

A collection of Python projects developed as part of my **QSkill Python Development Internship**. These projects focus on data analysis, introductory machine learning, numerical computing, and problem-solving using Python libraries.

## 👨‍💻 About This Repository

This repository contains three projects built to strengthen my practical Python programming skills and apply concepts through hands-on implementation.

## 📂 Projects

### 1. 📊 Student Performance Data Analysis

**File:** `Task1_Pandas_Analysis.ipynb`

Analyze student performance data using Pandas and Matplotlib.

**Key Features**
- Load and explore CSV datasets.
- Handle missing values and duplicate records.
- Perform data filtering, aggregation, and statistical analysis.
- Visualize relationships using bar charts, scatter plots, and a correlation heatmap.
- Derive insights from the data.

**Technologies:** Python, Pandas, Matplotlib

### 2. 🏠 House Price Prediction Using Linear Regression

**File:** `Task2_House_Price_Prediction.ipynb`

Build an introductory machine learning model to predict median house values using the California Housing dataset.

**Key Features**
- Explore and preprocess housing data.
- Split data into training and testing sets.
- Train a Linear Regression model.
- Evaluate predictions using MAE, MSE, RMSE, and R².
- Compare actual and predicted values using a scatter plot.
- Examine model coefficients.

**Technologies:** Python, Pandas, NumPy, Matplotlib, scikit-learn

### 3. 🧮 Interactive NumPy Matrix Calculator

**File:** `Task3_NumPy_Matrix_Calculator.ipynb`

Create an interactive, menu-driven calculator for performing matrix operations using NumPy.

**Key Features**
- Accept user-defined matrices.
- Perform matrix addition and subtraction.
- Perform matrix multiplication.
- Calculate matrix transposes.
- Calculate determinants of square matrices.
- Validate matrix dimensions and handle invalid inputs.

**Technologies:** Python, NumPy

## ▶️ How to Run the Projects

1. Open the required `.ipynb` notebook in this repository.
2. Click **Open in Colab** if the notebook provides that option, or upload the notebook to [Google Colab](https://colab.research.google.com/).
3. Run the notebook cells from top to bottom.
4. For Task 1, upload `student_performance.csv` when prompted, if the notebook uses the uploaded CSV file.
5. For Task 2, install any missing dependencies if necessary.
6. For Task 3, enter the requested matrix dimensions and values, then select operations from the menu.
